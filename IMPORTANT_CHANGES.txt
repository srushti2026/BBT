HOW TESTS WORK NOW:
===================

When transfer is submitted:
1. Send Money button is clicked
2. Application processes transaction
3. Wait method checks for success or error message (up to 10 seconds)
4. If success message appears -> Test PASSES
5. If error message appears -> Test FAILs as expected
6. If no message in 10 seconds -> Test FAILS with timeout
